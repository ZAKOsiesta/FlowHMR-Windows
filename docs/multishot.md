# 剪辑视频、跨镜头动作连接与原片相机

本文介绍剪辑视频跨镜头连接、原片相机按需恢复及人机配套导出的界面操作与 MCP 用法。依赖项、已知限制与设备验证范围详见 [依赖与验证范围](product-validation.md)。

---

## 1. 基本使用流程

同时启用「躯干优化」时，如果任务实际进入单人跨镜头连接，基础模型只重算第一遍已经确认的有效区间，复用同一人物特征和相机条件。人物离画、短碎段被排除或姿态断开时，不跨边界平滑，也不补造空档动作。报告中可查看每个优化区间的原片帧号与脚部误差。如果基础模型在此阶段中断，不会发布部分优化结果。

从原片中间开始处理时，单人跨镜头预览与人机配套导出保留原片起始偏移。VMD 通过显示键隐藏空档；FBX 的空档采用保持姿势并附带区间报告，不保证其他软件自动隐藏人物。

1. **导入视频与选择区间**：导入视频后按需框选处理区间和目标人物。帧号基于标准化后的 30 FPS 视频；界面从第 `1` 帧开始显示，而 MCP 接口与文件内部索引从 `0` 开始（结束帧均包含在内，例如界面 `46–225` 对应 MCP 的 `45–224`，共 180 帧）。
2. **开启跨镜头连接**：保持“跨镜头连接：自动”。单人剪辑视频会自动检测切镜并衔接各镜头动作；若视频无切镜，则自动沿用原有单段流程。多人模式下遇到切镜暂按原单段流程处理，并在界面给出提示。
3. **固定视角检查动作**：动作生成完成后，建议先在固定观察视角下检查动作表现。未能确认目标人物存在的时间段会自动隐藏人物，导出文件也会保留这些时间轴空档（不会用插值补帧伪造空档期动作）。
4. **按需恢复原片机位**：在顶部打开“视图”菜单并切换至“原片机位”。首次切换会排队解算原片相机，不会改动已生成的动作数据；解算完成后可查看逐镜头恢复状态，后续再次切换将直接复用已保存的相机结果。
5. **人机配套导出**：在导出窗口选择 `NPZ`、`VMD` 或 `FlowHMR FBX`，勾选“同时导出相机”。若相机尚未解算，系统会先自动完成解算，随后打包下载 `.zip` 压缩包（内含成套的人物动作、相机文件及时间段/近似说明报告，导入时需配套使用）。

## 2. 状态管理、切镜规则与角色导出说明

- **相机与动作状态解耦**：相机解算拥有独立的排队、运行、完成、失败和取消状态。相机解算失败或被手动取消，绝不会将已完成的人物动作冲掉或标为失败；重试相机时会复用已匹配的观测缓存，无需重新生成动作。
- **切镜检测异常回退**：若环境中缺少 `scenedetect` 依赖或未能完整读完所选视频区间，任务会自动退回原单段生成流程，并在连接报告中记录回退原因（用户主动取消任务仍会正常中止）。
- **跨镜头姿态衔接与碎段过滤**：
  - 切点两侧仅对比画面内可见度充足的关节（建立躯干朝向所需的核心关节也必须在画内）；当画内观测证据不足时，不会凭模型猜测强行断开镜头。
  - 确认为真实切镜或存在人物空档时，各区间独立生成动作，后一段衔接前一段末尾的水平位置与朝向，高度则统一对齐至公共地面。
  - 经可见性复核与切镜分段后，**不足 15 帧（0.5 秒）的碎片段会被自动剔除并转为空档**（源帧范围与原因记录在连接报告中），不对其启动动作生成或手指精修。若全片无合格区间，系统会提示调整选区。
  - 手指精修（HaMeR）报告会累加所有有效生成段的处理帧数、左右手覆盖帧数与采样量，并附带分段明细。
- **慢放与帧间边界**：慢放预览时，人物、骨骼与原片机位共用同一显示时钟。空档区间全程隐藏人物；切镜帧或空档边界前保持上一有效帧姿态，不会跨切镜或跨空档插值混合。
- **时间滤波滑块说明**：界面上的“滤波滑块”乘以 `3` 对应内部的 `smoothing_frames`（高斯平滑标准差 $\sigma$，单位：帧）。实现采用 `int(4 × sigma + 0.5)` 作为卷积半径，因此默认值 `0.04`（即 `0.12` 帧）对应的半径为 `0`，默认不做额外时间平滑。调大滤波可减轻高频抖动，但也会削弱动作力度与细节（手部动作同样经过该滤波）。
- **PMX 重定向与各导出格式边界**：
  - 切换为 PMX 角色后，通过界面导出该角色并勾选相机，系统会自动将角色的体型缩放与臀高偏移同步应用到配套相机上（多角色场景共享相机时，均匀缩放以首个选中的角色为准）。
  - 自定义重定向若对水平与垂直位移使用了**非等比例缩放**，将无法用单一相机尺度精确匹配；此时界面会自动禁用该角色的“原片机位”与“同时导出相机”选项并说明原因（角色预览、骨骼编辑与纯动作导出仍正常可用）。
  - 界面导出“通用 VMD”会带上当前角色的静态姿态校正；而 MCP 通用动作导出仍保持源人体契约。“当前角色 FBX”用于导出目标角色的骨骼与可选蒙皮（含空档时打包为带说明的 `.zip`），暂不提供配套相机；`VRMA` 与其他自定义模板同样暂不支持配套相机。

## 3. 固定机位 / 运动机位模式与 GeoCalib 图像重力

- **生成阶段的相机模式**：
  - **固定机位（默认）**：生成动作时使用固定观测方向与近似内参（跳过 VGGT），适合固定机位拍摄或轻微平移/推拉的素材。
  - **运动相机**：适合包含明显摇镜、俯仰或滚转的运动镜头，生成阶段会调用 VGGT 估计相机轨迹。
- **恢复原片机位时的图像重力（GeoCalib）**：
  - 生成完成后的“原片机位”是独立的后置恢复步骤。无论是**固定机位**还是**运动相机**模式生成的任务，在恢复原片机位时均会使用 **GeoCalib** 提取图像重力证据，以改善地面倾角恢复（建议在“模型”页面下载 **GeoCalib · 图像重力**，程序会在校验官方权重 SHA-256 后本地加载）。
  - GeoCalib 缺失不会阻断纯动作生成。当权重缺失/损坏、组件加载失败、设备不支持或个别镜头估计不稳定时，相机会自动回退至“人物倾斜 + 地面约束”估计，并在完成摘要与原片机位视图上方明确提示降级。
  - 重新打开历史回退任务（包括旧版本在固定机位模式下跳过了图像重力的历史结果）仍会按原记录显示降级提示；后续安装模型或升级软件不会自动重算或覆盖已保存的相机文件。

## 4. 修正用地面与预览显示地面

- **修正用地面**：直接参与动作后处理。设为“自动”时，每个有效生成段会先估计自身的原生地面高度，再以整段恒定垂直偏移对齐到公共地面（不会逐帧强行把人物最低点压死在地面上）。预览、相机恢复与导出均共享这一最终地面声明。
- **预览显示地面**：仅用于调节 3D 视图中的辅助网格高度，不会重新执行接触修正，也不改变导出的动作数据。

## 5. 导出配套与常见问题排查

- **严格成套导入**：导出的相机与人物动作共享同一源帧时间轴与世界坐标系，导入 DCC 软件时请一并保留空档说明与显示关键帧，切勿单独缩放或平移其中一方。`NPZ` 保留完整浮点内参；`VMD`（整数视角）与 `FBX`（平均焦距、中心主点）的格式近似详情均记录在随包导出的 `export-report.json` 中。
- **异常重试**：若相机恢复失败，可先正常导出纯人物动作，查看具体报错信息（如模型未下载或显存不足）后单独点击重试相机。MCP 端配套导出若中途失败，不会生成残缺的 `.zip` 文件，也不会覆盖已有的导出产物。MCP 工具详情请参考 [MCP 服务文档](mcp.md)。
