# 剪辑视频、动作与原片相机

本文说明剪辑视频连接、原片相机恢复及配套导出的界面与 MCP 用法。依赖、已知限制和已验证设备范围见 [验证说明](product-validation.md)。

## 普通使用流程

1. 导入视频，按需选择处理区间和目标人物。帧号基于标准化后的 30 FPS 视频；界面从第 1 帧显示，MCP/文件内索引从 0 开始，结束帧包含在内。例如界面 46–225 对应 MCP 的 45–224，共 180 帧。
2. 保持「跨镜头连接：自动」。单人剪辑会自动连接不同镜头；没有切镜时仍走原来的生成流程。多人加切镜暂按原流程处理，并在界面提示。
3. 生成完成后，先在固定观察视角检查动作。不能确认人物存在的时间段会隐藏人物，导出也保留这些空档；不要把空档当成已经恢复的动作。
4. 打开视图菜单，选择「原片机位」。第一次会排队计算相机，动作仍保留。相机完成后，可查看逐镜头说明；再次进入会复用结果。
5. 在导出窗口选择 NPZ、VMD 或 FlowHMR FBX，勾选「同时导出相机」。尚未计算的相机会先计算，完成后一起下载 ZIP。人物与相机需成套使用，保留报告与时间段文件。

相机状态独立于动作状态。计算失败或取消，不会把已经完成的动作判成失败。可以重试整个相机步骤，匹配的观测缓存会复用；重试不重新调用动作生成。取消与完成同时发生时，以实际返回的状态为准，已完成结果可能已经就绪。

自动切镜检测缺少依赖或未能读完整个所选区间时，任务会退回原来的生成流程，连接报告保留回退原因。回退不代表已确认视频没有切镜；用户取消仍会停止任务。

连接时，切点连续性只比较两侧都在画内的关节，建立身体方向所需的躯干关节也必须在画内；证据不足时不以模型猜测判定跳剪。画内不等于没有遮挡，因此这个判断仍有局限。确认为跳剪或存在人物空档时，各段分别生成，后段沿用前段末尾的朝向和水平位置，各段高度按公共地面处理。这个衔接约定不声称恢复了空档里的真实运动。

可见性复核及切点分段后，少于 15 帧（0.5 秒）的生成段会被排除，保留为空档，并在连接报告中列出源帧范围和原因；不会为这些碎段启动动作生成或手指精修。若没有合格段，会提示调整处理区间。手指精修报告累计所有生成段的处理帧数、左右手覆盖和采样量，并保留分段明细；处理帧数不含空档，覆盖量可以少于处理帧数。

换 PMX 角色后，通过界面导出对应角色与相机，才能带上该角色的尺度及预览偏移。通用 MCP 动作导出沿用原来的源人体规则，不会自动烘焙选中角色的预览调整。VRMA、其他 FBX 重定向配置和自定义模板暂不提供配套相机选项。

慢放时，人物、骨架与原片机位共用显示时间。空档会在整个帧间区间保持隐藏；切镜或空档边界前保持上一帧，不跨越边界混合姿态。逐帧与原速使用原始采样帧。

自定义重定向可能按不同的比例缩放竖直与水平位移。这种模式目前无法用同一个相机尺度准确配套，因此界面会关闭原片机位和该角色的配套相机选项，并说明原因；角色预览、编辑与单独动作导出仍可使用。普通 PMX 体型适配继续支持配套相机。多个角色共享相机时，均匀缩放仍以首先选中的角色为准，不保证所有体型的投影同时一致。

勾选相机不会改变同一导出选择中的人物文件。界面「通用 VMD」会包含当前静态校正；MCP 通用导出仍保持源人体契约。「当前角色 FBX」保留所用角色的骨架与可选蒙皮，带空档时返回 FBX 与空档说明组成的 ZIP，不提供配套相机；不能把它当作源人体 FlowHMR FBX。

## 默认值与研究样本

| 设置 | 新任务默认 | 已有研究对照参数 |
|---|---|---|
| 步数 | 20 | 40 |
| 滤波滑块 | 0.04 | 约 0.333333 |
| 内部 `smoothing_frames` | 0.12 帧 | 1 帧 |
| 接触修正 | 开启，`strong` | 开启，`normal` |
| 修正地面 | 自动 | 记录实际实验配置 |
| 相机模式 | 固定机位 | 按素材指定 |
| 跨镜头连接 | `auto` | 按实验记录 |

滤波滑块 × 3 等于 `smoothing_frames`，后者是高斯滤波的 sigma，单位为帧。实现采用 `int(4 × sigma + 0.5)` 的半径，因此默认 0.12 帧半径为 0，实际上不做时间平滑；1 帧研究设置不是默认值。加大滤波会减少抖动，也会削弱动作细节、产生发软感。手指也经过这一步，不能把手指的变化一概归因于接触修正。旧任务重跑继承其保存参数，不会被文档示例自动换成研究值。

旧版本试验性的可见手臂贴合阶段已移除，不再提供界面或公开 MCP 参数；读取历史记录不代表重新启用它。

## 两种相机模式

「固定机位」使用固定观测方向与近似内参，适合固定拍摄；纯平移或推拉素材可先尝试，再检查构图。素材有明显转向、俯仰或滚转时选「运动相机」，其观测估计需要 VGGT。相机模式影响生成时的条件；生成完成后的「原片机位」是独立恢复步骤，两者不是同一个开关。

GeoCalib 为原片机位提供图像重力证据，改善地面倾角恢复。推理组件随应用提供；请在「模型」下载 **GeoCalib · 图像重力**。程序校验官方权重后才加载，不会在推理时偷偷下载。它不阻断纯动作生成，但缺失、损坏、组件加载失败或设备不支持时，相机只能使用人物与地面估计，完成状态和原片机位会明确提示「已降级」。个别镜头的图像重力不稳定时也会提示，报告保留具体范围和原因。

固定相机模式保持原有的人物/地面估计路径，会明确标注未使用图像重力。历史回退结果重新打开也会提示；安装模型不会自动重算或覆盖已有相机。逐镜头报告只表示当前证据程度，不保证真实物理尺度或投影完全一致。近景、遮挡、出画和快速切镜仍需实际查看。

## 修正地面与显示地面

「修正用地面」参与动作后处理，自动时每个有效生成段先估计自己的原生地面，再以整段恒定高度平移到公共地面。它不逐帧把最低点压在地面上。单段保留原生高度；报告、预览、相机和导出共享最终声明。

预览中的地面高度只影响观看辅助平面，不能用它证明动作已修复，也不会重新执行接触修正。换体型后还可能有鞋底穿地、悬空及步幅差异；人体网格的地面检查不能替代目标角色检查。

## 导出与故障排查

相机与人物使用同一源帧号和同一世界变换。导出中的空档和显示键应一并保留。NPZ 保存完整浮点相机；VMD 的整数视角及可表达内参有限，报告记录其近似；FBX 也要按报告中的轴向、单位和时间范围载入。不要单独缩放或平移其中一个。

相机失败时可先导出纯动作，查看错误详情后重试。缺 VGGT 或主推理模型应先在「模型」检查；GeoCalib 缺失会明确提示降级。API / MCP 的相机状态和导出报告保留 `quality`，包含降级原因和镜头范围。MCP 配套导出失败不会发布半份 ZIP，原有文件默认也不覆盖。MCP 的具体工具和例子见 [MCP 服务](mcp.md)。
